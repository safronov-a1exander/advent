# advent — стенд для экспериментов с LLM по REST API

Полигон для практики: как устроен вызов модели по HTTP, что делают параметры
генерации, чем контролируется формат ответа, сколько это стоит и как честно
сравнивать модели между собой.

Стенд собран вокруг **одного сквозного продукта** — «Бюджет», ассистент по
личным тратам. Домен общий, меняется только то, что добавляет очередной шаг:
шаг 1 отвечает текстом, шаг 2 достаёт из банковской выписки структуру,
шаги 3–5 считают по ней остаток бюджета и выбирают модель под задачу,
шаг 6 выносит разговор в отдельную сущность — агента, шаг 7 сохраняет
разговоры между запусками, шаг 8 считает токены и лимит контекста, шаг 9 сжимает старую часть разговора
в сводку.

Язык — Go. Провайдер по умолчанию — DeepSeek (OpenAI-совместимый API),
но код провайдеро-независимый: меняется только `base_url` в `config.yaml`.

## Ветки

Один шаг — одна ветка, каждая ответвляется от предыдущей:

```
main → day-01 → day-02 → day-03 → day-04 → day-05 → improvements → day-06 → day-07 → day-08 → day-09 → day-10 → day-11 → day-12 → day-13 → day-14 → …
```

`main` — только инфраструктура. Код шага N содержит весь код шагов 1…N-1,
поэтому демо любого шага запускается со своей ветки, и по истории видно,
что именно добавил каждый шаг.

| шаг | ветка | тема | заметки |
|---|---|---|---|
| 1 | `day-01` | первый запрос к LLM через API | `docs/days/day01.md` |
| 2 | `day-02` | контроль формата ответа | `docs/days/day02.md` |
| 3 | `day-03` | способы рассуждения | `docs/days/day03.md` |
| 4 | `day-04` | температура и разнообразие | `docs/days/day04.md` |
| 5 | `day-05` | сравнение моделей | `docs/days/day05.md` |
| 6 | `day-06` | агент как отдельная сущность | `docs/days/day06.md` |
| 7 | `day-07` | разговор переживает перезапуск | `docs/days/day07.md` |
| 8 | `day-08` | работа с токенами | `docs/days/day08.md` |
| 9 | `day-09` | сжатие истории через summary | `docs/days/day09.md` |
| 10 | `day-10` | sliding window, sticky facts, ветки разговора | `docs/days/day10.md` |
| 11 | `day-11` | модель памяти: краткосрочная, рабочая, долговременная | `docs/days/day11.md` |

Пошаговый порядок от ключа до записи — [`docs/RUNBOOK.md`](docs/RUNBOOK.md).

## Управление

Приложение полностью интерактивно; демо-сценарии (`-script`) просто шлют
в него те же нажатия, что и человек.

| режим | команда | клавиши |
|---|---|---|
| чат | `advent chat` | `Enter` отправить · `Tab` панель параметров и блокнот · `Esc` вернуться в диалог · `Ctrl+J` перенос · `Ctrl+R` сброс контекста · `Ctrl+L` очистить · `Ctrl+P` спрятать панель · `Ctrl+N` новый агент · `Ctrl+O` список агентов · `Ctrl+B` ветки разговора · `Ctrl+D` что внутри агента · `Ctrl+T` токены по ходам |
| список агентов | `Ctrl+O` в чате | `↑↓` выбор · `Enter` открыть · `Ctrl+N` новый · `Ctrl+W` закрыть · `Esc` в диалог |
| ветки разговора | `Ctrl+B` в чате | `↑↓` выбор · `Ctrl+S` чекпойнт в текущей точке · `Enter` на ветке — перейти в неё, на чекпойнте — новая ветка от него · `Esc` в диалог |
| флот | `advent swarm -fleet agents/fleet.yaml` | — |
| сравнение стратегий контекста | `advent dialog -scenario scenarios/day09-compression.yaml`, `scenarios/day10-strategies.yaml` | — |
| сохранённые разговоры | `advent sessions`, `advent sessions -show <id>` · в чате `-new`, `-session <id>`, `-no-save` | — |
| сравнение | `advent lab -scenario ...` | `r` прогнать · `↑↓` вариант · `t` сводка · `Tab` панель и блокнот · `Esc` к результатам · `q` выход |
| одиночный запрос | `advent ask "вопрос"` | — |

В панели: `↑↓` — поле, `←→` — значение, `Enter` — ввести вручную
(старое значение затирается), `Esc` — отмена.

**Блокнот** — панель под окном диалога. В неё можно печатать руками, и туда
же демо-сценарий набирает комментарии посимвольно. Сделано ради видео:
в самой переписке остаётся только разговор с ассистентом, без подписей
«смотрите сюда». По той же причине заголовок окна и шапка экрана показывают
продукт.

Набор параметров растёт по дням и наследуется: на ветке дня N доступны все
параметры дней 1…N.

| появился | параметры |
|---|---|
| день 1 | `модель`, `system`, `стриминг` |
| день 2 | `max_tokens`, `stop`, `response_format`, `повторов` |
| день 3 | `стратегия` (прямой ответ / пошагово / мета-промпт / эксперты) |
| день 4 | `temperature`, `top_p`, `thinking`, `seed` |
| день 5 | `класс` (weak/medium/strong), `Ctrl+E` — прогнать вопрос на всех моделях |
| день 6 | параметры панели — это конфиг текущего агента; у каждого агента свои |
| день 8 | `лимит контекста` — свой потолок агента; флаги `-context-limit`, `-thinking` |
| день 9 | `контекст` (полная история / summary), `хвост как есть`, `сжимать каждые`; флаги `-context`, `-keep-last`, `-summarize-every` |
| день 10 | `контекст` дополнился sliding window и sticky facts; ветки разговора — `Ctrl+B`; в сценарии `advent dialog` — команды `checkpoint`/`branch`/`switch` и `branches: true` у варианта |
| день 11 | `память` (выкл / руками / агентом), `юзер`, `задача`, `слои в промпт`; слои — `Ctrl+M`, запись из поля ввода `/user ключ = значение`; флаги `-memory`, `-user`, `-task`, `-memory-scopes`, `-memory-dir`; команда `advent memory`; в сценарии — `newchat` и `remember` |
| день 12 | `профиль` — файлы из `profiles/*.md`: стиль, ограничения и дороги запросов; `/profile <id>` из поля ввода; флаги `-profile`, `-profiles-dir`; команда `advent profile`; в сценарии — `forbid` и `expect_by` |
| день 13 | `стадии` (выкл / руками / агентом) рядом с полем `задача`; `/stage` и `/step` из поля ввода; флаги `-task-state`, `-tasks-dir`; команда `advent task`; в сценарии — команда `stage` |
| день 14 | `инварианты` (выкл / промпт / промпт + проверка) и `набор правил` — markdown-файлы в `invariants/<набор>/`, в каждом только текст правила; флаги `-invariants`, `-invariant-set`, `-invariants-dir`; команда `advent invariants` |

В экране `lab` панель работает **слоем поверх YAML-сценария**: пустое поле
означает «как в сценарии», заполненное навязывается всем вариантам сразу.

## Быстрый старт

```bash
git clone <repo> && cd advent
cp .env.example .env               # и вписать ключ
go build -o bin/advent.exe ./cmd/advent
./bin/advent doctor
./bin/advent models
```

Ключ берётся из `.env` рядом с проектом (файл в `.gitignore`). Переменная
окружения, заданная в терминале, имеет приоритет над файлом. Альтернатива —
`config.local.yaml`:

```yaml
providers:
  - name: deepseek
    api_key: sk-...
```

## Запись видео

`scripts/demo.ps1` делает всё сам: собирает бинарь, открывает окно
фиксированного размера, стартует запись экрана через ffmpeg, прогоняет
сценарий, корректно останавливает ffmpeg.

```powershell
.\scripts\demo.ps1 -Name day01 -AppArgs @('demo','-script','scripts/day01.demo')
```

Записывается непрерывное видео (h264 mp4), а не серия скриншотов.
Захват идёт через `ddagrab` (Desktop Duplication API) с кропом по
прямоугольнику окна — `gdigrab -i title=...` на Windows Terminal
отдаёт чёрный кадр, потому что окно рисуется через DirectX.

Все дни за один заход (переключает ветки сам, в конце возвращает исходную):

```powershell
.\scripts\record-all.ps1            # -DryRun чтобы посмотреть план
```

Ручная запись без сценария:

```powershell
$r = .\scripts\record.ps1 -WindowTitle "advent" -Out recordings\manual.mp4 -NoWait
# ... работаем руками ...
.\scripts\stop-recording.ps1 -Process $r
```
