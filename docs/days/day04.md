# День 4 — Температура

Ветка: `day-04` (от `day-03`)

## Что добавляет этот шаг

Задание требует сравнить по **разнообразию** — значит разнообразие надо
измерить, а не описать словами. Появился `internal/metrics`:

- `MeanSimilarity` — среднее попарное сходство ответов между повторами
  по биграммам (Жаккар). `1.00` — модель повторилась дословно, `0.00` — тексты
  не пересекаются. Биграммы, а не отдельные слова: у любых двух ответов на одну
  тему совпадение отдельных слов высокое просто из-за общей лексики.
- `AllIdentical` — точное совпадение, выводится словом «(совпали)».

В сводке появилась колонка **СХОДСТВО** (при `repeat > 1`).

В панель приехали параметры сэмплирования: `temperature`, `top_p`,
`thinking`, `seed`. Крутить можно стрелками или ввести значение с Enter.
Потолок ползунка намеренно 3.0 при штатном диапазоне DeepSeek `[0, 2]` —
чтобы прямо в видео выставить 2.5 и получить 400 от API, не перезапуская
приложение. Параметры дней 1–3 остаются на месте и работают вместе с этими.

Два сценария вместо одного — потому что «точность» и «креативность» тянут
в разные стороны, и на одном запросе этого не показать:

| сценарий | что меряет |
|---|---|
| `scenarios/day04-temperature-creative.yaml` | идеи по экономии — разнообразие: СХОДСТВО падает с ростом t |
| `scenarios/day04-temperature-precise.yaml` | расчёт остатка бюджета — точность: УСПЕХ падает с ростом t |

Оба сценария — про одного и того же ассистента по тратам, и в этом смысл:
у продукта есть и счётная часть, и творческая, и настройка им нужна разная.

Шкала намеренно шире рабочей: **0 / 0.7 / 1.2 / 2.0 / 2.5**. Последнее
значение невалидно, и это заявленный результат — добавился `checks.expect_error`,
чтобы ожидаемая 400-я считалась успехом, а не сбоем прогона.

У DeepSeek диапазон `[0, 2]`, дефолт `1`,
на `2.01` прилетает `400 Invalid temperature value`.

## Проверено на живом API

Замеры на `deepseek-v4-flash`, оба сценария по три прогона:

| temperature | точность (расчёт) | сходство (идеи) |
|---|---|---|
| 0 | 3/3 | 0.38 |
| 0.7 | 3/3 | 0.05 |
| 1.2 | 2/3 | 0.03 |
| 2.0 | 0/3 | 0.00 |
| 2.5 | `400 Invalid temperature value, the valid range of temperature is [0, 2]` | — |

Две вещи, которые стоит сказать честно:

- **При `temperature = 0` полного совпадения нет.** Сходство 0.38 — самое
  высокое по шкале, но не 1.00. Детерминизма на распределённом инференсе
  не бывает; важно не то, что разброс нулевой, а то, что дальше он растёт.
- **Рассуждения приходится отключать.** С включённым reasoning ответ при
  нуле перестаёт быть воспроизводимым (цепочка рассуждений каждый раз своя),
  и колонка СХОДСТВО показывала ерунду: 0.07 при нуле против 0.33 при 1.2.
  В обоих сценариях стоит `thinking: disabled`.

Оба прогона вместе: 27 вызовов, около минуты, **$0.011**.

## На что смотреть при прогоне

1. Прогнать оба сценария:
   ```bash
   go run ./cmd/advent run -scenario scenarios/day04-temperature-creative.yaml
   go run ./cmd/advent run -scenario scenarios/day04-temperature-precise.yaml
   ```
2. **Проверить сообщение об ошибке на 2.5.** В `checks.expect_error` стоит
   подстрока `temperature`. Если DeepSeek ответит иначе (или молча обрежет) —
   поправь подстроку, иначе вариант покажется красным.
3. Не обещать в видео, что при `t=0` ответы совпадут дословно — на замере
   сходство 0.38. Правильная формулировка: при нуле разброс минимален,
   а не равен нулю.
4. Если на расчёте бюджета успех не проседает даже при `t=2.0` — модель
   слишком сильная для этой задачи. Возьми `-model deepseek-v4-flash`.

## Запись демо

Три части в **одно непрерывное видео** (`demo.ps1` умеет запускать
несколько прогонов подряд, не останавливая ffmpeg): два пакетных сценария
и ручная крутилка температуры в чате.

```powershell
.\scripts\demo.ps1 -Name day04 -MaxSeconds 1800 -AppArgsList @(
  @('lab','-scenario','scenarios/day04-temperature-creative.yaml','-script','scripts/day04-creative.demo'),
  @('lab','-scenario','scenarios/day04-temperature-precise.yaml','-script','scripts/day04-precise.demo'),
  @('demo','-script','scripts/day04-chat.demo','-title','advent · день 4 — температура вручную'))
```
