# День 3 — Разные способы рассуждения

Ветка: `day-03` (от `day-02`)

## Что добавляет этот шаг

Два способа посмотреть на одно и то же.

**Пакетно** — `scenarios/day03-reasoning.yaml`: четыре варианта одной задачи.
Многошаговые цепочки уже поддерживались движком со дня 2 (`steps` + `capture`
+ шаблоны), поэтому кода добавилось мало: в сводку приехала колонка **УСПЕХ** —
доля прогонов, где ответ верный.

**Руками** — в панели чата появился параметр `стратегия`:
`прямой ответ` / `пошагово` / `мета-промпт` / `эксперты`. Переключается на
лету, задаёшь тот же вопрос — и видишь разницу, не описывая YAML.
Промежуточные вызовы печатаются отдельными строками со своей задержкой,
токенами и ценой, так что цепочка «аналитик → инженер → критик → синтез»
видна целиком (`internal/tui/strategy.go`).

Параметры дней 1–2 (модель, system, max_tokens, stop, response_format)
остаются в панели и работают вместе со стратегией.

Шаг сквозного проекта: ассистент считает остаток бюджета по той же выписке,
которую вчера научился разбирать. «Точнее» здесь объективный факт, а не
мнение — у задачи единственный правильный ответ **38865**.

```
сентябрьские траты  2340+390+620+4150+1205+1480+870+3500+2960 = 17 515 ₽
снятие наличных     5 000 ₽ — тоже трата
Spotify 10 USD      × 90 = 900 ₽
возвраты            1800 + 480 = 2 280 ₽
не в счёт           перевод на копилку 10 000 ₽, августовский Ozon 1 990 ₽
траты               23415 − 2280 = 21 135 ₽
остаток             60000 − 21135 = 38 865 ₽
```

Четыре ловушки нарочно: операция не того месяца, внутренний перевод,
снятие наличных и сумма в валюте. Хотя бы одну прямой ответ обычно теряет —
именно на них и расходятся способы рассуждения.

Проверка — `must_contain: ["38865"]`, `repeat: 2`, так что видно не только
правильность, но и **стабильность** способа.

Четвёртый вариант — не один промпт с ролями, а четыре последовательных
вызова (аналитик → инженер → критик → синтез), где каждый видит результат
предыдущего. Это уже маленький мультиагентный конвейер, и он же самый дорогой
по токенам — на этом контрасте и строится вывод.

## Проверено на живом API

- **Рассуждения нужно отключать.** С включённым reasoning модель съедала
  весь `max_tokens`: 2000 из 2000 completion-токенов ушли в рассуждения,
  до ответа генерация не дошла, у всех вариантов `finish_reason: length`.
  В сценарии стоит `thinking: disabled` — заодно это честнее для сравнения:
  встроенный reasoning смазал бы разницу между способами промпта.
- **Разброс реальный.** Прогон на `deepseek-v4-flash`: прямой ответ 1/2,
  пошагово 2/2, мета-промпт 2/2, эксперты 1/2. Ошибка экспертов —
  36875 вместо 38865, ровно на 1990: в траты попал августовский Ozon.
- **Цена растёт быстрее точности.** Прямой ответ $0.0012, эксперты $0.0072 —
  вшестеро дороже, и при этом промахнулись на одном прогоне из двух.

Полный прогон дня: 16 вызовов, ~40 секунд, **$0.015**.

## На что смотреть при прогоне

1. Прогнать и посмотреть, разъехались ли способы:
   ```bash
   go run ./cmd/advent run -scenario scenarios/day03-reasoning.yaml -full
   ```
2. **Если все четыре способа дали 38865** — задача слишком лёгкая для
   `deepseek-v4-pro`, разница на видео не будет видна. Тогда:
   - переключись на слабую модель: `-model deepseek-v4-flash`;
   - либо добавь в `params` `thinking: disabled`, чтобы отключить встроенные
     рассуждения — тогда «решай пошагово» снова начнёт что-то менять;
   - либо усложни выписку в `data/statement.txt` (и не забудь пересчитать
     ответ в `checks.must_contain`).
3. Наоборот, **если промахиваются все** — проверь, что модель выводит
   `ОТВЕТ: 38865` без пробелов; при необходимости поправь `must_contain`.
4. Посмотреть в отчёте шаг «модель пишет промпт» — сгенерированный промпт
   там виден целиком, его интересно показать в видео.

## Запись демо

Две части в одно непрерывное видео: пакетный прогон и ручное переключение
стратегий в чате.

```powershell
.\scripts\demo.ps1 -Name day03 -MaxSeconds 1800 -AppArgsList @(
  @('lab','-scenario','scenarios/day03-reasoning.yaml','-script','scripts/day03.demo'),
  @('demo','-script','scripts/day03-chat.demo','-title','advent · день 3 — способы рассуждения вручную'))
```

Всего около двадцати вызовов, прогон идёт несколько минут — `-MaxSeconds` поднят.
